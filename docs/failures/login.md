# 실패 로그: 로그인

## 1. 로그인했는데 "접근할 수 없습니다"가 나온다
- **증상**: 구글 로그인은 됐는데 내 노트 화면에 "접근할 수 없습니다"가 뜬다.
- **원인**: 로그인한 구글 계정이 허용 계정이 아니었다. 서버 보안 규칙이 허용 계정 하나만 통과시킨다. 규칙이 정상 동작한 것이다.
- **해결**: 로그아웃하고 허용 계정으로 다시 로그인한다. 다른 계정을 쓰려면 `firestore.rules`의 허용 이메일을 바꿔 다시 배포한다.
- **재발 방지**: 안내 문구에 "다른 계정으로 로그인하세요"를 넣어 두었다. 계정을 바꾸려면 의사결정 문서도 갱신한다.

## 2. 구글 로그인 제공자는 코드로 켤 수 없다
- **증상**: 로그인 화면은 만들었지만 로그인이 시작되지 않을 수 있다.
- **원인**: Authentication의 구글 로그인 사용 설정은 콘솔에서 사람이 직접 눌러야 했다. 우리 도구로는 켤 수 없었다.
- **해결**: 파이어베이스 콘솔 → Authentication → 로그인 방법에서 Google을 사용 설정하고 지원 이메일을 고른다.
- **재발 방지**: 새 프로젝트를 만들면 로그인 코드를 쓰기 전에 이 설정부터 확인한다.
