# 실패 로그: Firestore 시작

## 데이터베이스를 만들려는데 403 오류
- **증상**: CLI나 도구로 Firestore를 만들면 "Cloud Firestore API has not been used in project ... or it is disabled" (403)가 난다.
- **원인**: 프로젝트에서 Firestore API가 아직 켜져 있지 않았다. 우리 쪽 도구로는 API를 켤 수 없었다.
- **해결**: 파이어베이스 콘솔 → Firestore Database → "데이터베이스 만들기"로 만든다(위치 `asia-northeast3`, 프로덕션 모드). 콘솔에서 만들면 API도 함께 켜진다. 그 뒤에 `firebase deploy --only firestore`로 규칙을 올린다.
- **재발 방지**: 새 프로젝트는 콘솔에서 데이터베이스부터 만든 뒤 규칙을 배포한다. 규칙을 올린 다음에는 로그인 없이 전체 목록을 요청해 막히는지(403) 확인한다.

## 비공개 글 검사는 "질문"의 형태까지 본다
- **증상(예방 기록)**: 공개 글 목록을 읽을 때 `visibility == public` 조건 없이 전체를 요청하면 규칙에서 거절된다.
- **원인**: Firestore 규칙은 요청한 질문 자체가 허용 범위 안에 있어야 통과시킨다.
- **해결**: 방문자는 공개 글만 묻고, 주인은 비공개 글을 따로 묻는다. 결과는 화면에서 합쳐 정렬한다. (색인 없이 동작한다.)
