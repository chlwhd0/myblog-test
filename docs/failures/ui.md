# 실패 로그: 화면(UI)

## 1. 숨겨야 할 버튼이 방문자에게 보였다
- **증상**: 로그인하지 않은 방문자에게도 "새 글 쓰기" 버튼이 보였다.
- **원인**: 버튼에 `hidden`을 줬지만, 버튼 스타일의 `display: inline-flex`가 `hidden`보다 우선해서 숨겨지지 않았다.
- **해결**: 스타일 맨 위에 `[hidden]{display:none!important}`를 추가했다.
- **재발 방지**: `display`를 직접 지정하는 요소에 `hidden`을 쓸 때는 이 규칙이 있는지 확인한다. 화면에서 숨기는 것은 보안이 아니다. 실제 접근 제한은 서버 규칙으로 한다.

## 2. 한글이 단어 중간에서 줄바꿈됐다
- **증상**: "계속"이 "계 / 속"처럼 글자 사이에서 끊겼다.
- **원인**: 기본 줄바꿈이 글자 단위로 일어났다.
- **해결**: 본문에 `word-break: keep-all`과 `overflow-wrap: break-word`를 주었다.
- **재발 방지**: 새 화면을 만들 때 같은 설정을 넣는다.

## 3. 설명 문구가 광고처럼 읽혔다
- **증상**: 첫 화면의 소개 문구가 홍보 문구처럼 느껴진다는 지적을 받았다.
- **해결**: 사실만 담담하게 쓰는 문구로 바꿨다.
- **재발 방지**: 사용자가 요청하지 않은 문구, 영역, 숫자는 임의로 넣지 않는다. 넣어야 하면 먼저 묻는다. 예시 데이터는 예시라고 표시한다.
